# כללי המערכת

## הקצאת משימה

1. רק מנהל יכול ליצור ולהקצות משימה.
2. אי אפשר להקצות משימה לעובד חסום.
3. סופרים לעובד רק משימות במצב `todo` או `in_progress`.
4. אם הספירה שווה למגבלה האישית שלו, ההקצאה נחסמת.
5. לאחר הקצאה מוצלחת נוצרת התראה לעובד.

## התקדמות וסיום פרויקט

`progress = done tasks / all tasks * 100`

- פרויקט ללא משימות מציג 0% ואינו מסתיים אוטומטית.
- אם קיימת לפחות משימה אחת וכל המשימות במצב `done`, הפרויקט עובר ל־`completed` ונשמר זמן הסיום.
- בכל מצב אחר הפרויקט הוא `in_progress`.

## נוכחות ושכר

- לעובד יכולה להיות רק רשומת נוכחות פתוחה אחת.
- אי אפשר לבצע יציאה ללא כניסה פתוחה.
- רשומה ללא שעת יציאה לא נכללת בחישוב השכר.
- שכר חודשי הוא סכום שעות העבודה הסגורות כפול השכר השעתי של העובד.
